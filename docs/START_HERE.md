# 启动教程（第一次用这个项目，照这个做）

> 按下面步骤操作即可把系统跑起来。
> 全程只需要 4 个操作：**打开终端 → 敲命令 → 等它跑 → 打开浏览器**。

---

## 第 0 步：确认你已经有的东西（一次性）

| 东西 | 在哪 | 没有的话 |
| --- | --- | --- |
| 项目文件夹 | 项目根目录（本文以 `tiktok-ecommerce-agent` 为例） | 在（已在） |
| 虚拟环境 | 项目里的 `.venv` 文件夹 | 已在（装依赖时建的） |
| 配置文件 | 项目里的 `.env` | 已在（真实 Key 已填好） |

> `.env` 里现在是**真实数据源**：商品 = SocialCrawl（免费额度 Key），货源 = 找家纺网。
> 不用再改任何东西。

---

## 第 1 步：打开终端（命令窗口）

按键盘 **`Win` + `R`**，弹出小窗口，输入 `powershell`，回车。
会打开一个深蓝色/黑色的窗口，这就是终端。后面所有命令都在这里敲。

> 以后每次启动项目都要先开这个终端。

---

## 第 2 步：启动后端（第 1 个终端）

把下面三行**依次**粘贴进终端，每行敲完按一次回车：

```powershell
cd <项目根目录，如 D:\work\tiktok-ecommerce-agent>
.\.venv\Scripts\activate
python -m uvicorn tiktok_ecommerce.api.app:create_app --factory --port 8000
```

**成功的样子**（终端最后会出现）：
```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

看到这一行就成功了，**这个终端不要关**（关了后端就停了）。

> 注意：这三行是「cd → 激活环境 → 启动服务」的顺序，一行都不能少。
> 报 `Failed to find application` = 第三行少了 `--factory`。

---

## 第 3 步：启动前端（第 2 个终端）

再按 `Win+R` → `powershell` → 回车，**新开一个终端**，粘贴：

```powershell
cd <项目根目录>\frontend
npm run dev
```

**成功的样子**：
```
  VITE v6.x.x  ready in xxx ms
  ➜  Local:   http://localhost:5173/
```

看到就成功了，**这个终端也先别关**。

> 第一次运行如果报 `'npm' 不是内部或外部命令` = Node.js 没装，去 nodejs.org 下载安装后重开终端。
> 如果报 `vite: not found`，先跑一次 `npm install`（装依赖，只需一次）。

---

## 第 4 步：打开聊天界面

打开浏览器（Chrome/Edge），地址栏输入：

```
http://localhost:5173
```

回车，就能看到 **TikTok 电商助手** 聊天界面了。

---

## 第 5 步：怎么用（3 分钟学会）

### 5.1 快捷指令（点一下就行）
界面顶部有几个圆角按钮，点一下自动发送：
- `帮我分析 ボックスシーツ 冬用 能不能卖` → 跑完整选品（真实采集+分析+货源+素材）
- `找 牛奶绒床笠 四件套 的货源` → 找家纺网真实货源
- `生成 法兰绒床笠 的上架素材` → 生成日文标题/关键词/描述

### 5.2 自己打字问
在底部输入框打字，按回车发送。支持中文/日文：
- 「帮我分析 ボックスシーツ 能不能卖」（选品）
- 「找 四件套 的货源」（货源）
- 「生成 床笠 的上架素材」（素材）
- 「日本站物流怎么算」（电商引导，会告诉你查官方）

### 5.3 只聊电商
**非电商话题**（天气、八卦、代码……）会收到：
> 「我是TikTok电商选品助手，只回答商品选品、竞品分析、找货源、上架素材……不在我的回答范围内」

这是设计好的范围限定，不是报错。

### 5.4 完整工作台（可选）
顶部导航第二个「选品工作台」是完整版：选品类/勾阶段/填关键词/运行 → 四块结果面板。
聊天界面适合快速用，工作台适合细看结果。

---

## 第 6 步：每天怎么开机用（就 3 步）

1. 开终端 1 → `cd <项目根目录>` → `.\.venv\Scripts\activate` → `python -m uvicorn tiktok_ecommerce.api.app:create_app --factory --port 8000`
2. 开终端 2 → `cd <项目根目录>\frontend` → `npm run dev`
3. 浏览器开 `http://localhost:5173`

关掉 = 两个终端按 `Ctrl+C`。

---

## 常见问题（先看这里）

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 前端打不开（页面转圈/报错） | 后端没起来或端口被占 | 看终端 1 有没有报错；`Win+R`→`powershell` 敲 `netstat -ano | findstr 8000`，有占用就先 `taskkill /PID <数字> /F` |
| 后端报 `address already in use` / `10048` | 8000 端口被旧后端占着 | 同上，杀掉旧进程再重新启动 |
| 聊天回复「无法连接后端服务」 | 前端和后端没同时跑 | 确认两个终端都开着 |
| 选品很慢（10~40 秒） | 真实采集 + LLM 分析，正常 | 等「正在处理」动画结束 |
| 提示要 Key / 数据源状态条变红 | `.env` 里 Key 被改了 | 用记事本打开 `.env`，检查 `SOCIALCRAWL_API_KEY` 一行为 `sc_OQ6...` 开头 |

## 数据/花费说明（透明）

- **商品数据**：SocialCrawl 真实 API，搜索 1 次 = 1 credit（新号送 100，用完需充值，见 `docs/HOW_TO_GET_DATA.md`）
- **货源数据**：找家纺网真实 API，免费
- **分析/生成**：DeepSeek LLM（按量，单次约 0.001 元级）+ BGE 向量库（本地 Milvus，免费）
- 一次完整选品 ≈ 搜索 1~2 次 + 评论 1~3 次 ≈ 3~5 credits ≈ 首次免费

> 换数据源（TikHub/FastMoss/1688）只需改 `.env` 一行，见 `docs/RUN_GUIDE.md` 第 5 节。
